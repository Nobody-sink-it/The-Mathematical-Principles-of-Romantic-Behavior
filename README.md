# 恋爱行为的数学原理

**A Mathematical Theory of Romance**

英文名呼应 Claude E. Shannon 的 *A Mathematical Theory of Communication*，将讨论对象从通信转向恋爱行为。

尝试用经济学、信息论、认知心理学与博弈论的语言，理解两个人如何相遇、产生吸引、认识彼此，以及在长期相处中互相塑造。

这个项目从一组日常问题出发：为什么条件很好的人，也未必适合自己？为什么明知不合适，还是会心动？为什么有些关系越不快乐，反而越难离开？又是什么，让两个人在共同生活中越来越舒展，或越来越疲惫？

我们希望把这些经验拆成明确的问题、变量与机制，再逐步发展为可以运行、比较和修正的模型。

## 总论讨论什么

| 主题 | 主要问题 |
| --- | --- |
| 价值与评价 | 同一个人，为什么会在不同主体、群体与人生阶段获得不同评价？ |
| 特征与适配 | 个人条件、主观感知与两个人之间的契合，怎样分别描述？ |
| 心动与判断 | 早期吸引为什么会与长期相处的判断发生冲突？ |
| 信息与认识 | 展示、情境、噪声与持续接触，怎样改变我们对一个人的认识？ |
| 搜索与选择 | 继续寻找、投入当前关系与保留其他选择之间，怎样形成取舍？ |
| 投入与承诺 | 拥有多少、实际兑现多少，以及离开需要付出多少，有什么区别？ |
| 长期相互塑造 | 关系怎样影响个人状态，而状态变化又怎样反过来改变关系？ |

## 写作与发布路线

完整总论作为持续更新的母稿保留，面向阅读的文章则按具体问题独立展开：

1. 为什么条件很好的人，也未必适合你？
2. 为什么明知不合适，还是会强烈心动？
3. 从上头到下头：我们究竟怎样认识一个人？
4. 为什么总觉得下一个更好，却迟迟无法确定关系？
5. 为什么有些关系越不快乐，反而越难离开？
6. 一段关系，是怎样慢慢改变两个人的？

以上是基础篇的拆分计划。后续专题会进一步进入破冰、关系推进、磨合、家庭协作等具体情境。

## 从文章走向建模与仿真

正文负责把问题与机制讲清楚；技术附录展开变量定义、参数、推导与算法；仿真则比较不同条件下的行为与结果。

我们计划围绕四个模块推进：

| 模块 | 研究对象 | 计划展开的内容 |
| --- | --- | --- |
| 认识与感知更新 | 回复、邀约、见面、守约及修复等交互事件 | 观测指标、潜在状态、缺失信息、概率更新与误判 |
| 搜索与双向匹配 | 接触机会、双方意愿与关系选择 | 搜索成本、可得范围、停止规则与匹配过程 |
| 投入与关系推进 | 时间分配、支持、回应与承诺 | 投入收益、互惠策略、沟通方式与关系状态转移 |
| 长期相处与退出 | 压力、冲突、修复与个人状态 | 信任、满意度、退出成本与双人耦合动力学 |

例如，把“对方是否愿意继续了解”转化为模型问题，需要先记录邀约是否接受、取消后是否重新安排，以及双方当时的日程约束，再估计下一次实际见面的概率。

每个仿真模块将明确：

- 输入与输出：模型接收哪些信息，预测什么事件或状态。
- 假设与规则：参数怎样影响观察、判断、行动与后续状态。
- 运行方法：环境、依赖、示例配置与随机种子。
- 实验结果：比较对象、评价指标、参数变化及复现步骤。

## 欢迎怎样的讨论与贡献

可以通过 Issue 提出问题，也欢迎通过 Pull Request 改进文字、公式与后续代码。

讨论时，尽量指出具体章节或公式，并附上理由。例如：一个反例、一处变量定义冲突、一条更合适的文献，或者一项可以比较不同解释的实验设计。

我们尤其希望逐步回答：同一种交互现象，有哪些不同解释？需要增加什么信息才能区分？一个模型在什么条件下有效，又会在哪里失效？

让问题变得具体，让推导能够检查，让实验可以复现，是这个项目继续发展的方向。
